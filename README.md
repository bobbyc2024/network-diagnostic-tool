# Network Diagnostic Tool

A simple Bash-based network diagnostic tool for macOS, designed to help troubleshoot common connectivity and network configuration issues.

## 🌐 Features

- Displays local IP address
- Identifies the default gateway
- Tests internet connectivity
- Displays DNS server and resolution information
- Detects whether VPN traffic is active
- Displays the active network interface

## 🛠️ Built With

- Bash
- macOS networking utilities

## ▶️ Usage

Run the script with:

```bash
bash network_check.sh
```
